# 캠퍼스 부수기

가상의 모 대학교 캠퍼스를 하늘 위 자유 시점에서 조준해 무너뜨리는 브라우저 게임입니다. 설치 없이 링크만 열면 바로 할 수 있습니다.

**▶ 플레이: https://elliott-json-park.github.io/campus-smash/**

## 조작

- 무기 없을 때: 좌클릭 드래그 회전, 우클릭 드래그 이동, WASD 이동, Q/E 회전, 휠 확대
- `1`–`7` 무기 선택 (기관포 · 유도미사일 · 수류탄 · 운석 · 낙뢰 · 조준 파괴포 · 먼작귀), 같은 번호를 다시 누르면 해제
- 좌클릭 발사, 우클릭 드래그 시점 회전
- 조준 파괴포: 우클릭 한 번 = 조준경
- `Ctrl` + 우클릭 누르고 있기 = 망원 확대 (휠로 배율)
- `R` 처음 시점 · `M` 소리 · `H` 조작법 접기

PC 브라우저(Chrome, Edge 권장)에서 마우스로 하는 걸 기준으로 만들었습니다.

## 사용한 것

- [three.js](https://threejs.org) r128 (MIT)
- 효과음 일부: [Kenney](https://www.kenney.nl) Sci-Fi Sounds · Impact Sounds (CC0)

방문자 수 집계를 위해 Google Analytics를 사용합니다.
