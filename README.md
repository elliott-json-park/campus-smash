# 캠퍼스 부수기

캠퍼스 건물과 남산, N서울타워까지 무너뜨리는 브라우저 게임입니다. 설치 없이 링크만 열면 바로 할 수 있고, 휴대폰 세로 화면을 기준으로 만들었습니다.

**▶ 플레이: https://elliott-json-park.github.io/campus-smash/**

## 하는 법

1. 닉네임을 적고 모드를 고릅니다.
   - 타임어택: 1분, 랭킹에 올라갑니다.
   - 자유 파괴: 시간 제한 없이 마음껏, 랭킹에는 올라가지 않습니다.
2. 아래 무기를 고르고 화면을 눌러 발사합니다. 건물이 무너질 때 큰 점수가 들어오고, 7초 안에 연달아 무너뜨리면 점수가 최대 3배까지 오릅니다.
3. 끝나면 점수와 순위가 나옵니다.
   - 자랑하기: 카메라를 직접 돌려 부서진 캠퍼스 앵글을 잡고 사진으로 저장하거나 보냅니다.
   - 공유하기: 게임 링크를 보냅니다.
4. 게임 중 📷 버튼(PC는 `P`)으로 언제든 화면을 캡처할 수 있습니다.

- 랭킹: 타임어택 한 판 최고 점수. 1분을 다 채운 판만 올라갑니다.
- 남산은 맞히면 패이고 그을리지만 점수는 없습니다. 점수는 N서울타워를 무너뜨릴 때만 들어옵니다.

## 무기

| 무기 | 쓰는 법 |
|---|---|
| 기관포 | 누른 채로 끌면 연사. 오래 쏘면 과열 |
| 미사일 | 솟구쳤다가 조준점에 내리꽂힘. 누르고 있으면 계속 발사 |
| 낙뢰 | 조준한 자리에 번개가 정확히 떨어짐 |
| 레일건 | 건물을 꿰뚫어 뒤에 있는 것까지 관통 |
| 운석 | 건물을 부술수록 충전되는 필살기 |

휴대폰: 무기를 고른 상태에서 한 손가락은 발사, 두 손가락은 이동과 확대입니다. 같은 무기를 다시 누르면 무기를 내리고 한 손가락으로 시점을 옮길 수 있습니다.
PC: `1`~`5` 무기, 좌클릭 발사, 우클릭 드래그 회전, `WASD` 이동, 휠 확대, `R` 처음 시점, `M` 소리, `P` 캡처.

정각원, 종각, 팔정도 불상은 부서지지 않습니다.

## 구조

- `index.html`: 화면(입장, 게임 중 표시, 결과, 랭킹)과 스타일
- `js/world.js`: 지형, 건물(외벽 창호, 옥상 난간과 설비), 절벽, 구름바다, 남산과 N서울타워 배경
- `js/game.js`: 파괴 물리, 무기, 효과음, 1분 판 진행, 결과 사진과 공유
- `js/rank.js`: 랭킹 서버 통신
- `data/campus.js`: 1m 정밀 지형과 건물 형상
- `server/`: 랭킹 API (Cloudflare Workers + D1, 무료 플랜). 배포는 `server/`에서 `wrangler deploy`, 서명 키는 `wrangler secret put SECRET`

## 사용한 것

- 지형과 건물: 서울시 S-MAP, 지도: © OpenStreetMap 기여자 (ODbL)
- [three.js](https://threejs.org) r128 (MIT)
- 글꼴: [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL 1.1), 한글 2,350자로 줄여 넣음
- 효과음 일부: [Kenney](https://www.kenney.nl) Sci-Fi Sounds, Impact Sounds (CC0)

방문자 수 집계를 위해 Google Analytics를 사용합니다. 랭킹에는 닉네임과 점수만 저장합니다.
